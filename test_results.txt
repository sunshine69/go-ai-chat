## Project Summary
- **Language**: Pure Go (no AI SDKs, no external frameworks except readline + godotenv)
- **Lines of code**: ~2932 lines across main source files
- **Purpose**: Console AI chat client with MCP server support for tool calling
- **Architecture**: JSON-RPC 2.0 protocol implementation, SSE streaming responses
- **Features**: Session management, system commands, multi-model support, MCP stdio/TCP

- `chat/main.go`: Main REPL + command handler (~950 lines) — the heart of the app
- `chat/mcp-client.go`: JSON-RPC 2.0 client for MCP protocol (~140 lines)
- Supports streaming with reasoning_content, tool_calls accumulation by index
- File attachment support (text + images via base64 data URLs)
